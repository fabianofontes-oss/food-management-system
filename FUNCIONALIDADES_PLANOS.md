# 📦 FUNCIONALIDADES DO PEDIUFOOD

## VISÃO GERAL

O sistema possui **24 módulos** organizados em **5 categorias**.
Você pode criar planos ativando/desativando módulos pelo painel Super Admin.

---

## 🟢 MÓDULOS CORE (Sempre Incluídos)

Estes módulos são **obrigatórios** em todos os planos:

| Módulo | Descrição | Valor Percebido |
|--------|-----------|-----------------|
| **Dashboard** | Painel com visão geral de vendas, pedidos do dia, faturamento | Base |
| **Cardápio/Produtos** | Cadastro de produtos, categorias, fotos, preços | Base |
| **Pedidos** | Receber e gerenciar pedidos (status, impressão) | Base |
| **Configurações** | Horários, formas de pagamento, dados da loja | Base |

**Custo base:** Estes módulos justificam o preço mínimo do plano.

---

## 🔵 MÓDULOS DE VENDAS

| Módulo | Descrição | Público-Alvo | Valor Agregado |
|--------|-----------|--------------|----------------|
| **PDV** | Ponto de venda para balcão, caixa registradora digital | Lanchonetes, Padarias | ⭐⭐⭐ Alto |
| **Delivery** | Gestão de entregadores, rastreamento, taxa por km | Pizzarias, Hamburguerias | ⭐⭐⭐ Alto |
| **Mesas** | Comandas por mesa, divisão de conta, QR Code | Restaurantes, Bares | ⭐⭐⭐ Alto |
| **Reservas** | Agendamento de mesas, calendário, confirmação | Restaurantes finos | ⭐⭐ Médio |
| **Garçons** | App para garçom, pedidos direto na mesa | Restaurantes grandes | ⭐⭐ Médio |

## 🔧 COMO CONFIGURAR OS PLANOS

1. Acesse `/admin` como Super Admin
2. Vá em **Planos**
3. Crie/edite planos definindo:
   - Nome e preço
   - Limite de pedidos (`orders_per_month`)
   - Módulos ativos (checkboxes)
4. Os clientes só verão os módulos do plano deles

---

## 📝 PRÓXIMOS PASSOS

1. **Defina os planos** que você quer oferecer
2. **Me passe os nomes e preços** → Eu crio no Stripe
3. **Configure no banco** → Vincula `stripe_price_id`
4. **Teste o fluxo** → Trial → Checkout → Ativo
